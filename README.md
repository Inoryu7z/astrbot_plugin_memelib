# 潮流梗库（astrbot_plugin_memelib）

把精选网络流行梗全量注入系统提示词，补充 LLM 的世界知识，让模型能听懂、会在合适的语境下玩梗。

## 为什么是全量注入

梗是"引述式"表达，触发信号在字面（原话、谐音、名场面台词），不在语义相似。语义（向量）检索会系统性漏掉字面不相似的触发，且检索质量押注在解释文本上，不可控。精选库规模可控（百条级、约万 token），全量注入的成本可以接受；防止"人设被压成梗小鬼"靠注入姿态（初级档"酌情"引导），不靠召回。

## 配置项

| 配置 | 说明 |
|---|---|
| 注入等级 | `初级（酌情使用）`（默认）：引导语含"酌情"，建议模型情境契合时再用；`完整注入`：直接给出梗库，不设克制。两档的梗库内容完全相同，只换引导语 |
| 初级档引导语 / 完整档引导语 | 可自行替换文案，留空则回退默认 |
| 自定义梗库（JSON） | 留空使用插件内置 `memes.json`；填写后整体替换内置库。格式错误自动回退内置库并记录警告 |

## 梗库格式

`memes.json` 与自定义梗库均为 JSON 数组，每条四个字段：

```json
[
  {
    "name": "city不city",
    "aliases": ["city啊不city"],
    "meaning": "形容时髦、洋气，带夸张惊叹语气，用于评价装扮或事物很潮",
    "example": "你这新造型也太 city 不 city 了！"
  }
]
```

- `name`：最通行的原写法，谐音/方言/混写保留原样
- `aliases`：变体说法，没有给 `[]`
- `meaning`：一句话讲清含义与使用情境、语气，不写来源考据和 URL
- `example`：像真实网友随口说的话，不要教科书腔

## 更新梗库的两种方式

1. 插件版本更新：随新版 `memes.json` 分发
2. 用户自助：在 WebUI 配置面板的"自定义梗库"里粘贴自己的 JSON

## 备注

- 仅在 LLM 请求前向系统提示词追加内容，不提供任何指令；梗库为空时不注入
- 无第三方 Python 依赖
