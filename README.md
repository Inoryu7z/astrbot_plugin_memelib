# 🤡 重生之我是梗小鬼 · 潮流梗库

模型的世界知识更新滞后，难以覆盖中文互联网快速更替的流行梗。本插件在每次 LLM 请求前，将一份精选流行梗库全量追加到系统提示词中，使模型能够理解对话中出现的梗，并在语境契合时自然使用。

插件提供两档注入力度，默认的初级档以“听懂”为首要目标，对主动使用加以克制，避免玩梗压过原有说话风格；完整档不限制主动使用，适用于本身就以玩梗为定位的 Bot。

---

## ✨ 功能概览

- 内置 50 条精选梗：以抖音、B站等平台近期仍在大量使用的热梗为主，附带少量出圈较久、至今通用的常青梗
- 两档注入，梗库内容完全相同，仅引导语不同
- 梗库与两档引导语均可在 WebUI 配置面板自定义，无需修改代码
- 自定义梗库解析失败时记录日志并自动回退内置库，不影响正常对话

## 🎚️ 两档注入

| 档位 | 引导语 | 行为取向 |
|---|---|---|
| 初级（酌情使用）（默认） | 以下梗库用于让你听懂对话中出现的流行梗。回复时保持你原有的说话方式与人设，只在语境自然契合时酌情使用，禁止滥用，禁止为了用梗而强行套用。 | 理解优先，主动使用有门槛，保持原人设 |
| 完整注入 | 以下梗库用于让你听懂对话中出现的流行梗。回复时保持你原有的说话方式与人设。 | 理解优先，主动使用不作限制 |

两档引导语均可在配置面板替换，留空则恢复默认。

## 实际注入效果

插件只向系统提示词末尾追加内容，原有提示词保持不变。注入块用成对标签 `<MemeLib>` 包裹，每次请求先清除旧块再重新注入；即使系统提示词被跨请求复用，也不会出现堆叠或残留。

以下为两档注入后的完整结构（梗库正文仅展示前 3 条，实际为全部 50 条）：

**初级档：**

```
你是一个猫娘，用可爱的语气和主人聊天。

<MemeLib>
以下梗库用于让你听懂对话中出现的流行梗。回复时保持你原有的说话方式与人设，只在语境自然契合时酌情使用，禁止滥用，禁止为了用梗而强行套用。
1. 不烧心｜含义：本义食材实在、吃着不难受，出自短剧摊主台词“贵是贵了点，但不烧心”；引申靠谱、没猫腻、不踩雷、让人放心｜用法：夸人夸物皆可，如“这活干得不烧心”“这朋友交得不烧心”
2. 已读乱回｜含义：被问到不想答的问题时刻意答非所问，不撕破脸又能敷衍过去，主打边界感｜用法：被催婚、问工资、查岗时用，对方问“工资多少”，回“今天天气真好”
3. 我的刀盾（What the dog doing/刀盾狗）｜含义：外网 Vine 宠物视频“What the dog doing（这狗在干嘛）”快读空耳，表“这啥玩意儿，看不懂”的懵圈｜用法：看到离谱迷惑画面直接甩“我的刀盾？”，纯吐槽不带恶意
……（共 50 条）
</MemeLib>
```

**完整档：**

```
你是一个猫娘，用可爱的语气和主人聊天。

<MemeLib>
以下梗库用于让你听懂对话中出现的流行梗。回复时保持你原有的说话方式与人设。
1. 不烧心｜含义：……｜用法：……
2. 已读乱回｜含义：……｜用法：……
3. 我的刀盾（What the dog doing/刀盾狗）｜含义：……｜用法：……
……（共 50 条）
</MemeLib>
```

注入过程发生异常时整体跳过，不中断对话。

## 🤔 为什么采用全量注入

玩梗的触发信号主要在字面，如原话、谐音、名场面台词，而非语义相似。模型主动使用某个梗时，用户消息中往往不包含该梗的关键词，语义检索难以召回；同时梗的实际含义经常与字面无关，短文本向量相似度的可靠性有限。

在梗库保持绝对精选、规模为百条级、约数千字的前提下，全量注入的 token 成本可控。防止梗库压过原人设，依靠的是初级档引导语所确立的使用姿态，而不是检索机制。

## 📚 梗库格式

内置库与自定义库均采用行文本，每行一条：

```
梗名（变体1/变体2）｜含义：实际表达什么，可附来源与语气｜用法：使用语境、传达的情绪，附自然例句
```

- 变体组可省略；分隔符支持全角 `｜` 与半角 `|`
- 空行与以 `#` 开头的注释行会被忽略，行首序号可有可无
- 同时兼容 JSON 数组输入，字段为 `name` / `aliases` / `meaning` / `usage`

注入时会统一重新编号。任何一条缺少梗名或「含义」字段都会被判定为格式错误，日志中标明行号，并整体回退内置库，避免注入不完整的梗库。

## 注意事项

1. 插件仅在 LLM 请求前追加系统提示词，不拦截消息、不修改回复；梗库为空时不注入。
2. 完整档不约束玩梗频率，原人设可能被稀释，建议仅在娱乐向 Bot 上使用。
3. 内置梗库在插件加载时读取一次；自定义梗库按内容哈希缓存，不会在每次请求时重复读盘。
4. 纯标准库实现，无第三方依赖。
